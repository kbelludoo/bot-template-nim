Arquitetura Canônica de Alta Resiliência

Projetada para rodar 24/7 sem interrupções humanas e consumindo menos de 5MB por processo.

🔄

Worker Supervisor com Auto-Recovery

Cada um dos 18 bots roda isolado em uma corrotina assíncrona supervisionada. Exceções não derrubam o motor: o supervisor aplica backoff exponencial com jitter e restaura o bot automaticamente.

🛡️

Watchdog Anti-Congelamento

Loop em background verifica o timestamp de batimento cardíaco (heartbeat) de todos os bots a cada 10s. Se um socket ficar preso por mais de 45s, o watchdog sinaliza travamento e dispara recuperação.

⚡

Circuit Breaker Adaptativo

Detecta instabilidades de rede na API remota e desarma a conta por intervalos progressivos (5m até 1h), evitando detecções de spam ou bloqueios de IP na VPS.

🎯

Pacing Orgânico Humano

Variação gaussiana ($\pm 20\%$) e intervalos aleatórios de latência (300ms a 650ms), reproduzindo o comportamento de um usuário real.

🚀

Compilação Cruzada Zig para Linux

Geração de binários estáticos x86_64 limpos direto do Windows para execução instantânea em qualquer VPS Ubuntu, Debian ou Alpine.

🌐

Dashboard & Telemetria JSON

Servidor HTTP embutido expondo status e métricas em `/api/status`, pronto para monitoramento em tempo real ou scraping com Prometheus.

Como Usar e Compilar

Comandos rápidos para compilar e implantar em produção.

1. Compilação Cruzada para Linux (x86_64 via Zig)

# Compilação nativa para Linux direto do Windows com Zig nim c --os:linux --cpu:amd64 --gcc.exe:zigcc-linux-gnu.bat --gcc.linkerexe:zigcc-linux-gnu.bat -d:ssl -d:release -o:bot-template-linux-nim main.nim

2. Execução com Auto-Recovery no Linux (systemd)

# Instalação do serviço de auto-reinício contínuo no sistema operacional sudo cp nim-bot.service /etc/systemd/system/ sudo systemctl daemon-reload sudo systemctl enable --now nim-bot
