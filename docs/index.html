Engenharia de Alta Resiliência

Criado para operar 24/7 em VPS com consumo mínimo de recursos e proteção contínua contra bloqueios.

🔄

Worker Supervisor (Auto-Recovery)

Padrão Erlang/OTP onde tarefas de cada conta são isoladas. Exceções transitórias ou falhas críticas são contidas e a rotina é reiniciada com backoff exponencial e jitter.

🛡️

Watchdog Anti-Congelamento

Monitor global em background que acompanha o batimento cardíaco (heartbeat) de cada conta, detectando sockets congelados ou chamadas sem timeout em menos de 45s.

⚡

Circuit Breaker Adaptativo

Detecta falhas consecutivas de rede e desarma automaticamente a conta por intervalos crescentes (5m a 1h), evitando bloqueio de IP ou captcha contínuo.

🎯

Pacing Orgânico & Anti-Detecção

Variação gaussiana ($\pm 20\%$) nos intervalos de ação e latência humana calculada (300ms a 650ms), eliminando padrões mecânicos de clique.

🚀

Zero-GC ARC/ORC em Nim

Pegada de memória abaixo de 5MB, sem pausas de Garbage Collector e compilado como binário ELF estático nativo para Linux x86_64.

🌐

Telemetria HTTP Integrada

Servidor HTTP assíncrono nativo embutido com endpoints JSON rápidos (`/api/status`) e dashboard web pronto para integração com Prometheus ou Grafana.

Como Usar

Construído para compilação local ou cruzada imediata para Linux via Zig.

1. Compilação Cruzada para Linux (x86_64 via Zig)

# Compilação estática ultra-otimizada diretamente do Windows nim c --os:linux --cpu:amd64 --gcc.exe:zigcc-linux-gnu.bat --gcc.linkerexe:zigcc-linux-gnu.bat -d:ssl -d:release -o:bot-template-linux-nim main.nim

2. Execução com Auto-Recovery no Linux (systemd)

# Instalação do serviço de auto-reinício contínuo sudo cp nim-bot.service /etc/systemd/system/ sudo systemctl daemon-reload sudo systemctl enable --now nim-bot
